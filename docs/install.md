# Install

The normal way to install FitKit is Obsidian's community plugins browser, covered in the README. This page is for the alternatives: installing a beta build with BRAT, or installing manually from a GitHub release.

FitKit needs the [Dataview plugin](https://github.com/blacksmithgu/obsidian-dataview) to render history tables and recent-session views, whichever way you install FitKit itself.

## Installing with BRAT

BRAT tracks a plugin's repository directly, so you get updates ahead of the community plugin directory.

To install FitKit with the [BRAT community plugin](https://github.com/TfTHacker/obsidian42-brat):

1. Install BRAT.
2. Add `https://github.com/paulchiu/obsidian-fitkit` as a beta plugin.
3. Enable FitKit from Obsidian's community plugins list.

## Installing manually

To install manually from a release:

1. Download `main.js`, `manifest.json`, and `styles.css` from the release.
2. Put them in `<vault>/.obsidian/plugins/fitkit/`, creating the folder if needed.
3. Reload Obsidian, then enable FitKit from the community plugins list.
